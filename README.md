
# SE1 Git Laboratory

## Project Description
A simple interactive welcome page created for the Software Engineering 1 Git and GitHub laboratory.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub

## Features
- Welcome page with a responsive layout
- Styled button
- Interactive welcome message

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Click the **Click Me** button to display the welcome message.

## Learning Objectives
- Practice Git commits and version control.
- Publish a project using GitHub.
- Create and merge feature branches.
- Practice pull requests and code review.
